# Utvärdering

## Vad vi byggde

Vi skapade en Todo-applikation med frontend och backend där användaren kan lägga till, ta bort och markera uppgifter som klara. Under projektets gång lade vi även till funktioner som filtrering av todos och dark mode för att göra applikationen mer användarvänlig och snyggare.

Frontend byggdes i React och backend i ASP.NET/C#.

---

# Samarbete

Samarbetet i gruppen fungerade väldigt bra under hela projektet. Vi använde GitHub för versionshantering och arbetade med branches, commits och pull requests för att kunna arbeta parallellt utan att skriva över varandras kod.

Vi kommunicerade kontinuerligt under arbetets gång och hjälpte varandra när problem uppstod. Eftersom vi under den stora delen av projektet satt tillsammans på plats var det mycket enklare att kommunicera och hjälpa varandra.

---

# Problem och utmaningar

Vi hade ej så mycket problem men vi skapade en merge conflict för att träna på konfliklösning i github.

Projektets merge conflicts uppstod i App.jsx när delar av frontend-koden refaktoriserades och flyttades ut till separata komponenter och API-filer samtidigt som flera personer arbetade i samma fil.

Vi löste konflikterna tillsammans genom att jämföra ändringarna och mergea koden korrekt via GitHub.

---

# Vad som gick bra

GitHub-arbetet fungerade väldigt bra och vi lyckades använda branches och commits kontinuerligt under hela projektet. Vi fick också bättre förståelse för hur merge conflicts fungerar i praktiken och hur viktigt det är med tydlig kommunikation när flera arbetar i samma projekt.

Frontend och backend fungerade bra tillsammans och vi lyckades implementera flera funktioner utöver grundkraven. Vi som grupp arbetade effektivt och hjälpte varandra när någon fastnade.

---

# Vad vi hade gjort annorlunda

Om vi hade gjort om projektet hade vi planerat branch-strukturen ännu tydligare från början och kanske använt en separat dev-branch istället för att mergea direkt till main/master.
Vi gjorde eftersom projektet var relativt litet och vi ville hålla workflowet enkelt

Vi hade även kunnat testa vissa funktioner tillsammans oftare under utvecklingen för att upptäcka eventuella problem tidigare.
