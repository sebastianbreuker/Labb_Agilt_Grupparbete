# 📝 Todo App

En enkel Todo-applikation byggd i React och ASP.NET/C# som skapades som grupparbete i kursen Agil Systemutveckling.

Projektets fokus låg inte bara på själva applikationen utan även på samarbete och arbete med GitHub, branches, pull requests och merge conflicts.

---

# ✨ Funktioner

- ➕ Lägg till todos
- ✅ Markera todos som klara
- 🗑️ Ta bort todos
- 🔍 Filtrera todos
- 🌙 Dark mode

---

# 🛠️ Tekniker

## Frontend
- React

- Vite

## Backend
- ASP.NET Core
- C#
