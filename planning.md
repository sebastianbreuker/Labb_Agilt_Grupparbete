# Task Tracker - Planning
## Produktidé
Vi ska skapa en enkel Todo i en fullstacklösning med c# och react typescript där användaren kan:
- lägga till tasks
- visa tasks
- markera tasks som klara
- ta bort tasks
Tasks ska sparas i en databas
---
# User Stories
1. Som användare vill jag kunna lägga till en task.
2. Som användare vill jag kunna se alla tasks.
3. Som användare vill jag kunna markera tasks som klara.
4. Som användare vill jag kunna ta bort tasks.
5. Som användare vill jag att tasks sparas mellan körningar.
